# Вузол IoT у симуляторі Wokwi (ПЗ 5, IoT-варіант проєктного треку)

Для студентів, які поєднують самостійну роботу з курсовою з дисципліни «Мікропроцесорні системи», але не мають плати.

1. На https://wokwi.com створіть проєкт **ESP32 → MicroPython** і замініть вміст `main.py` і `diagram.json` файлами цього каталогу.
2. Запустіть симуляцію. У Serial Monitor щодві секунди з’являються рядки JSON з показниками давача DHT22
   (температуру й вологість можна змінювати, клацнувши на давачі).
3. Скопіюйте вміст Serial Monitor у файл, наприклад `wokwi-log.txt` (приклад – `sample-log.txt`).
4. Створіть ключ пристрою (адміністратор): `POST /api/keys` з тілом `{"name": "esp32-wokwi-1"}`.
5. Надішліть показники на свій сервер:
   ```
   node tools/device.mjs --replay wokwi-log.txt --key wp_…
   ```

Wokwi в браузері не може звернутися до `localhost` вашого комп’ютера, тому дані передаються через лог.
Справжня плата ESP32 з Wi-Fi надсилає ті самі рядки JSON запитами POST безпосередньо (`urequests.post`), якщо сервер
запущено з `HOST=0.0.0.0` і плата в тій самій мережі. Без плати і без Wokwi: `node tools/device.mjs --simulate 10 --key wp_…`.
